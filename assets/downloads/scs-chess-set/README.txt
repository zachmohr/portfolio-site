SCS Chess Set — laser-cut sheet metal chess set by Zach Mohr (https://zachmohr.work/projects/scs-chess-set)

HEADS UP: I have not built this board yet. Material thickness and cut tolerances
vary by material and vendor, so check the fit (especially the squares in the board
plate and the pieces in their bases) and adjust the CAD if needed before ordering
a full set.

All parts are STEP files ready to upload to SendCutSend (or any laser-cutting service).
