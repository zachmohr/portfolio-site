Memorial Flag Box

Custom memorial flag display box incorporating the recipient's dog tags and bullet casings from their 21-gun salute. Features a triangular flag compartment with custom-cut glass, a channel for the casings and dog tags, and a live-edge spalted panel. Another sketch-to-build project — high detail work for a meaningful purpose.
