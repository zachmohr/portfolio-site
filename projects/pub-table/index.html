Pub Table

Pub table with a wood slab top filled with black epoxy for the voids and a welded steel base with extreme splayed joint angles. The base was a particularly difficult weld — getting all four legs to meet at compound angles required careful layout and fixture work. Later built a matching side table for the same client using the same X-base concept with a walnut and green epoxy river top.
