Memory Holder

A wall-mounted walnut display for preserving memories from life's milestones. A string runs through the tray, tensioned by custom-made brass cleats, allowing champagne and wine corks to be drilled and strung up to commemorate special occasions — engagements, weddings, and other celebrations. Photos can be clipped to the string as well. The brass hardware was made specifically for this piece, complementing the warmth of the walnut.
